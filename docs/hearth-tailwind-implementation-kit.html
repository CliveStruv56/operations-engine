01 — Theme

Tokens in, utilities out

With the theme installed, the whole system speaks in semantic utilities: bg-canvas, text-ink, text-subtle, text-faint, border-edge, bg-accent, text-accent-deep, bg-grounded-tint. Rule one of the system: faint is the lightest colour allowed for real text — there is no legal grey below 4.5:1.

07 — The contract

Ten rules that keep the AA badge honest

  • 1Text floor. text-faint (#6F6355, 5.5:1) is the lightest legal colour for any real text, placeholders included. edge colours are borders, never text.
  • 2Accent budget. Max three filled-accent elements per view — brand mark, active mode, Send. Everything else uses accent-tint + text-accent-deep.
  • 3Grounded is scoped. grounded classes touch only trust states: vault chip, vault switch, grounded badges. Never decoration, never generic success.
  • 4Serif discipline. font-display only at 22px and above (greeting, section titles). Nav, buttons and labels are always font-ui.
  • 5Focus is focus-visible. Every interactive element: focus-visible:ring-2 ring-accent/40 ring-offset-2 with the offset colour matching its surface (ring-offset-canvas / -sidebar / -card).
  • 6ARIA drives styling. Mode picker is role="radiogroup" with aria-checked: variants; vault toggle is role="switch". State and style can't drift apart. Add arrow-key handling to the radiogroup.
  • 7Composer input holds 16px on mobile. text-base sm:text-[15px] — anything under 16px makes iOS Safari zoom on focus.
  • 8Send ↔ Stop. Send disables on empty/whitespace; during streaming it becomes Stop, and Stop is never disabled. Don't auto-scroll during streaming — pin the viewport to the top of the new message.
  • 9Mode overflow. Below xl, render four pills + a "More ▾" menu. The row never wraps to a second line.
  • 10One shadow. shadow-hearth belongs to the composer alone; cards get shadow-card or nothing. Depth comes from white-on-cream surfaces, not stacked shadows.

## 2. Project state at handoff

### Built and working

- **Core platform:** multi-tenant auth (Supabase JWT → FastAPI JWKS/HS256), tenant resolution via `X-Tenant-Id`, Postgres RLS isolation, streaming chat, hybrid vault retrieval (pgvector + tsvector + RRF), citations, presigned uploads, LiteLLM alias routing, usage metering.
- **API:** FastAPI at `apps/api`. All 82 tests pass. CI runs lint, type-check, and isolation suite.
- **Worker:** ingestion pipeline (download → Docling parse → chunk → embed → store) at `apps/worker`. 10 chunker tests pass.
- **Web:** Next.js 16 / React 19 / Tailwind 4 at `apps/web`. Build passes; TypeScript strict; one minor lint warning (`detail` unused prop in `app/app/projects/[id]/page.tsx:171`).
- **Groundwork module data spine:** schema, seeds, portfolio page, project room with 9 tabs, tasks, documents registry, funding, budget, risks, conditions, stakeholders. 20 module tests pass.

### Not yet built

- **Groundwork value features:** AI-drafted monthly report, feasibility study, funding bid; health-card PDF; Draft with AI modal and polling.
- **Core Phase 1 pages:** `/app/settings`, `/app/usage`.
- **Billing:** Stripe checkout, portal, webhooks (re-sequenced after Groundwork module per `docs/groundwork/ASSUMPTIONS.md` #7).

### Known blockers for pilot onboarding

1. 4 high-severity transitive web dependency vulnerabilities (`sharp`, `postcss`, `brace-expansion`).
2. CORS defaults are development-only/permissive.
3. Groundwork stage sign-off and gate-toggle edge cases are not enforced server-side.
4. Drafting/health-card workflows are not implemented.

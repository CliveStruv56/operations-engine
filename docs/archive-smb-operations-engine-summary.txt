WHY GLM 5.2 IS NOT THE DEFAULT
────────────────────────────────────────────────────────────────────────────────

GLM 5.2 is excellent — near-frontier quality, 1M context window, MIT license — but
at $4.40 per million output tokens, it costs $379/month for your volume versus
$32 for DeepSeek V4 Flash. That's 12× more expensive for the same throughput.

Use GLM 5.2 only when:
  • A task demonstrably fails on DeepSeek V4 Pro
  • A premium-tier customer explicitly pays for "best-in-class AI"
  • You're doing a high-stakes client demo

For 95% of SMB operational tasks, GLM 4.7-Flash (FREE) or DeepSeek V4 Flash
($0.28 output) is perfectly adequate.


MULTI-TENANT ISOLATION STRATEGY
────────────────────────────────────────────────────────────────────────────────

Architecture: Bridge Model (shared compute, isolated data)

  • PostgreSQL Row Level Security (RLS) enforces tenant isolation at the database
    level. Every tenant-scoped table has a tenant_id column and an RLS policy that
    filters rows based on current_setting('app.current_tenant'). Even if application
    code forgets a WHERE clause, the database prevents cross-tenant data leakage.

  • Tenant resolution happens in FastAPI middleware: custom domain lookup first,
    then JWT token fallback. The resolved tenant_id is stored in a ContextVar and
    passed to PostgreSQL via SET app.current_tenant on every connection.

  • Rate limiting is per-tenant via Redis: Starter = 60 req/min, Professional = 300,
    Enterprise = 1,000. This prevents noisy neighbours without dedicated compute.

  • Feature toggles are stored as JSONB in the tenants table, allowing per-tenant
    module enablement (slides, documents, finance, meetings, calendar).


WHITE-LABEL CAPABILITIES
────────────────────────────────────────────────────────────────────────────────

  • Custom domains via Cloudflare for SaaS — automatic SSL provisioning with
    zero customer action required. Supports thousands of hostnames per domain.

  • Per-tenant CSS theming — primary/secondary colors, logo upload, font selection.
    Implemented via CSS custom properties (--primary, --secondary) set at runtime
    based on tenant config fetched on page load.

  • Module toggles — each tenant can enable/disable features based on their plan.
    The React frontend reads the features JSONB and conditionally renders nav items.

  • Branded email notifications via Resend with tenant-specific From addresses.

  • API key generation for tenant integrations (webhooks, third-party connections).

FINAL RECOMMENDATION
────────────────────────────────────────────────────────────────────────────────

Start with the GLM 4.7-Flash FREE tier for all routine tasks. It handles email
drafting, calendar parsing, and simple summarization at zero cost. Add DeepSeek
V4 Flash as a fallback for document analysis and meeting summaries. Reserve
DeepSeek V4 Pro for financial analysis and complex reasoning. Use Groq's free
tier for all transcription. This keeps your AI costs under $15/month while
delivering genuine value to SMB customers.

The total infrastructure cost of ~$30/month at 50 tenants means you break even
at approximately 1 paid tenant. Everything beyond that is pure margin. This is a
viable, profitable business model from day one.
